1 · Connect YouTube

Checking…
  1. Open console.cloud.google.com, create a project, and enable YouTube Data API v3.
  2. OAuth consent screen: choose External, then add your Google account under Test users.
  3. Credentials → Create credentials → OAuth client ID → Desktop app. Download the JSON. On the hosted server, choose Web application instead and add https://<your-server>/oauth2callback under Authorized redirect URIs.
  4. Paste the JSON below (or the client ID and secret) and press Save, then Connect.
A Google API project only gets public uploads after it passes Google's free audit. Before that, videos you upload stay private. Test-mode logins also expire after 7 days, so you'll need to reconnect. Request the audit, or publish the consent screen, to lift both limits. Each upload uses about 1,600 of the 10,000 daily API units, so the limit is roughly 6 uploads a day.
